JavaScript Grade Calculator

A grade calculator that calculates student's grade based on their score out of 100.

How I built it

  1. Designed the user interface with an input field for the score and a submission button.
  2. Wrote JavaScript logic to capture the user input when the button is clicked.
  3. Implemented conditional statements to map numeric scores to letter grades.
  4. Rendered the calculated grade dynamically onto the web page using DOM manipulation.

Technologies Used

  • HTML
  • CSS
  • JavaScript

Personal Budget Decision Tool

A website built using HTML, CSS and JavaScript that helps users decide whether they can afford to buy something based on their budget.

How I built it

  1. Created form inputs to capture user income, existing expenses, and the target item's cost.
  2. Styled the application with responsive layouts to ensure accessibility across desktop and mobile screens.
  3. Developed JavaScript calculations to compare remaining disposable income against the item cost.
  4. Added logical checks to output an immediate "Affordable" or "Not Affordable" decision with tailored feedback.

  • CSS
  • JavaScript

Simple Calculator

A calculator that adds, subtracts, multiplies and divides.

How I built it

  1. Structured the grid layout for the operator buttons, number keys, and the clear display screen.
  2. Mapped event listeners to each button to append the clicked characters into a mathematical expression string.
  3. Utilized evaluation logic to compute final totals when the equal sign is triggered.
  4. Added error handling to prevent crashing during invalid actions like dividing by zero.

Technologies Used

  • HTML
  • CSS
  • JavaScript
